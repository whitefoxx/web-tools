Prompts

Select text on any page and run one of these on it without leaving: the answer opens in a popover, on whatever model localmd is set up with. Translate and Explain ship as worked examples, and “Ask…” has no prompt at all — it asks you for one. Write your own for anything you do often. (The speech bubble beside them on the toolbar takes the passage to localmd to keep talking instead.)

What ${lang} becomes. Free text — "formal Japanese" is a fine answer. Leave it empty to follow your browser's language.

How to write a prompt

${content} — the text you selected. Leave it out and the selection is added at the end of your prompt, in triple quotes.

${lang} — the language set above, so one prompt serves every language.

Leave the prompt empty and the page asks you for it each time — what you type becomes the prompt, variables and all. That is what “Ask…” is.

Browser data

Your bookmarks, history, reading list and recently closed tabs — off by default, and each one separate. Switch on only what you want localmd to be able to read; switching one off revokes it immediately. This is the only place they can be granted: a web page cannot ask for them, and neither can the assistant.

Site scripts experimental

Persistent rules that run on matching pages (hide ads, inject CSS/JS). Your agent creates them with your confirmation — this list is your override: pause or delete any of them here.

CLI agents dev build · testing only

A development/testing affordance only, present in this dev build so a CLI agent can drive the extension while it is being worked on — it is absent from the shipped build. Driving the browser from a CLI agent as a product is WebCLI's job, not this extension's; localmd Connect ships to talk to localmd.app alone.
