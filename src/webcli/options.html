WebCLI
Open source whitefoxx/web-tools Documentation

Connection

WebCLI has no agent of its own. It dials a small daemon on your own machine — nothing else can reach it — and the agent you run talks to that daemon over plain HTTP on 127.0.0.1.

npx skills add whitefoxx/web-tools -g
Step 2 — ask your agent to use the browser

If you would rather start the daemon yourself
npx -y github:whitefoxx/web-tools

Site scripts

Page rules that keep running on the sites they match — hide the clutter, restyle a page, run a small script. Your agent writes one and you approve it; this list is the other half of that deal: read what it does, pause it, delete it.

Site scripts are switched off in Chrome.

They are written by your agent, not shipped inside WebCLI — so Chrome runs them in an isolated world it keeps behind a switch only you can flip. Until you do, a rule here is saved but inert. Every other tool works without it.

Open WebCLI's details page → turn on Allow user scripts → come back here.
